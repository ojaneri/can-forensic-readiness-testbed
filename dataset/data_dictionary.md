# Data Dictionary

| Field | Description |
|---|---|
| `experiment_id` | Experiment identifier. |
| `timestamp_epoch_s` | Wall-clock timestamp in Unix epoch seconds. |
| `relative_time_s` | Seconds elapsed since the beginning of the experiment. |
| `attack_label` | Phase label: `baseline`, `spoofing`, `flooding`, or `recovery`. |
| `arbitration_id` | CAN arbitration ID in hexadecimal without `0x` prefix. |
| `dlc` | Data Length Code. |
| `payload_hex` | CAN payload bytes encoded as uppercase hexadecimal. |
| `semantic_label` | Human-readable semantic label generated by the simulator. |
| `source_component` | Component inferred from the ID and phase. |
| `decoded_speed_kmh` | Decoded speed for ID `0x100`, when applicable. |
| `notes` | Additional textual notes copied from the simulator/logger. |
