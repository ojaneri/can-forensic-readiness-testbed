# Web Search Results — Initial Notes

## Automotive CAN testbeds

1. **A CAN Bus Security Testbed Framework for Automotive Cyber-Physical Systems** — Wiley / DOI 10.1155/2022/7176194. Open, adaptable, low-risk CAN testbed based on real data.
2. **can-train-and-test: A curated CAN dataset for automotive intrusion detection** — Computers & Security 2024 / arXiv 2308.04972. Dataset from four vehicles, equivalent attacks, replayable logs.
3. **VitroBench** — Vehicular Communications 2023. COTS ECU bench platform for in-vehicle networks.
4. **Enhancing Autonomous Vehicle Security: An Adaptive CAN Bus Testbed** — IEEE. Flexible testbed with API generated from DBC.
5. **Adaptive Fuzz Testing for Automotive ECUs: A Modular Testbed** — ACM 2024. Low-cost components, fuzzing, and real-time analysis.
6. **CANBench** — BYU. Open-source physical testbed built with inexpensive components.

## Security evaluation and tools

1. **ICSim** — instrument cluster simulator using SocketCAN.
2. **Caring Caribou** — CAN/UDS exploration and fuzzing toolkit.
3. **can-utils** — standard SocketCAN utilities.
4. **python-can** — Python library for CAN interfaces and virtual backends.
5. **FAV-NSS** — FPGA/HIL framework for IDS/IPS validation on CAN.
6. **CANsec** — practical CAN security evaluation tool.
7. **Evaluation of CAN Bus Security Challenges** — open review in PMC.

## Datasets

1. **ROAD dataset** — real-world CAN intrusion detection dataset.
2. **can-train-and-test** — curated CAN dataset for IDS evaluation.
3. **HCRL Car-Hacking Dataset** — widely used CAN attack dataset.
4. **can-sleuth** — evaluation of automotive IDS datasets.
5. **OTIDS** — older CAN IDS dataset.
6. **CAN-MIRGU** — moving-vehicle CAN attack dataset, VehicleSec 2024.
