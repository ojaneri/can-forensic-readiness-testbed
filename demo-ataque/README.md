# Observer Demo — Software-Defined CAN Attack

Public URL:

https://admin.janeri.com.br/adriana/artigo/testbed/demo-ataque/

## Purpose

Client-side demonstration page for observers:

- **Start attack** button;
- animated console showing commands, inputs, and outputs;
- simulated vehicle dashboard;
- live CAN frame table;
- attack time and phase;
- quantitative findings and evidence hashes.

## Safety

The demo is 100% client-side. It does **not** execute server-side commands and does **not** attack any real network or hardware. It replays artifacts from experiment `005_real_attack_software` for educational and paper-demonstration purposes.
