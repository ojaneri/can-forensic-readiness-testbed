# Overleaf package — article IEEE v6

Upload all files in this folder to Overleaf and set `main.tex` as the main document.

Included:

- `main.tex` — IEEEtran paper source
- `references.bib` — BibTeX references
- `IEEEtran.cls` and `IEEEtran.bst` — local IEEEtran files for portability
- `figures/*.pdf` — paper figures

Recommended Overleaf compiler: pdfLaTeX.
