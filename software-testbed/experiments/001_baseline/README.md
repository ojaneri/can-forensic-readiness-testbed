# Experiment 001 — Baseline

Objective: capture normal CAN traffic generated by simulated ECUs.

## Procedure

Terminal 1:

```bash
sudo ../../scripts/setup_vcan.sh vcan0
../../scripts/run_logger.sh vcan0 .
```

Terminal 2:

```bash
../../scripts/run_ecu_sim.sh vcan0
```

Stop with Ctrl+C after 30–60 seconds.

## Expected evidence

- `candump.log`
- `frames.csv`
- `manifest.json`

## Metrics

- Number of frames.
- Observed IDs: `0x100`, `0x120`, `0x188`, `0x300`.
- SHA-256 hashes of evidence files.
